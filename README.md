# DistilBERT-Based Movie Review Sentiment Analysis

## Project Overview
This project focuses on movie review sentiment analysis using DistilBERT, a lightweight transformer-based language model. It classifies IMDb movie reviews into positive and negative sentiments using Natural Language Processing (NLP).

## Objectives
- Analyze movie reviews using NLP techniques.
- Use DistilBERT for sentiment classification.
- Train and evaluate the model using the IMDb dataset.
- Predict sentiment for new movie reviews.

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- DistilBERT
- IMDb Dataset
- PyTorch
- NLP

## Project Workflow
1. Load the IMDb movie review dataset.
2. Preprocess and tokenize the text.
3. Load the pre-trained DistilBERT model.
4. Fine-tune the model using the training data.
5. Evaluate model performance.
6. Predict sentiment for new movie reviews.

## Evaluation Metrics
The model performance is evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score

## Project File
- `Copy_of_sentiment.ipynb` – Jupyter Notebook containing the project implementation.

## How to Run
1. Open the notebook using Google Colab.
2. Run the cells step by step.
3. Follow the instructions in the notebook to train and evaluate the model.

## Conclusion
This project demonstrates how transformer-based models like DistilBERT can be used for movie review sentiment classification.
